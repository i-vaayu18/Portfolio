03
PYTHON · SMTP · EXCEL · AUTOMATION

AutoMailerPro

AutoMailerPro is a Python-based email automation tool designed to send personalized bulk emails directly from an Excel sheet.

It supports Gmail SMTP, personalized messages, multiple attachments and configurable delays between emails for a simple and practical automation workflow.

The project uses Gmail App Password authentication and provides a simple workflow for automating newsletters, announcements and reminders.
